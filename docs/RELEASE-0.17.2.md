# 0.17.2 — автоматические пробуждения без остановки боя

- Требование EXP на каждом уровне равно тройному прежнему требованию: `3 * round(60000 * 1.1^earned)`. Множители получения Base/Job EXP не меняются.
- Первое бесплатное пробуждение после 99/50 и дальнейшие уровни автоматически выбирают одно из семи усилений с одинаковой вероятностью. Повторные усиления по-прежнему перемножаются; классовые ранги выдаются каждые пять уровней.
- Окно выбора больше не открывается. Пробуждение не ставит игру на паузу, не сбрасывает кнопки движения и не останавливает джойстик. Обычная ручная пауза работает как прежде.
- Панель показывает уровень/ранг, урон, HP, скорость атак, темп навыков, радиус, множитель защиты, повторы, прогресс опыта и последнее полученное усиление.
- Уже выбранные усиления старых сохранений остаются. Накопленные незавершённые выборы распределяются автоматически, старое окно не восстанавливается. Доля заполнения шкалы переносится умножением остатка EXP на три; метка версии предотвращает повторное умножение при следующей загрузке. Обычная пауза после восстановления сохранения сохраняется.

Проверки: тройной порог на нескольких уровнях, отсутствие автоматической паузы и потерянного движения, все семь случайных исходов, классовые ранги, перенос очереди и прогресса старых сохранений. Chromium/WebKit проверяют движение при получении уровня, отсутствие окна, показатели панели и восстановление забега.
