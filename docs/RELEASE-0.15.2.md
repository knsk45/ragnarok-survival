# 0.15.2 — спрайты без зелёных заглушек

Загрузчик монстров устанавливает обработчики до назначения `src`, повторяет неудачный запрос не более двух раз и использует локальный резервный кадр при ошибке или ожидании дольше 1,2 секунды. После успешной загрузки оригинала отрисовка возвращается к нему. Временный индикатор ожидания больше не выглядит как зелёный квадратный монстр.

Резервные кадры всех 65 монстров включены в один JS-ресурс, поэтому не требуют отдельных сетевых запросов. Они получены из оригинальных локальных PNG удалением только APNG-чанков `acTL`, `fcTL`, `fdAT`: пиксельные данные `IDAT`, палитра и прозрачность сохранены без перерисовки. Исходные файлы и их хеши не изменены. Повторная сборка: `node tools/build-sprite-fallbacks.cjs`.

Одиночные и небольшие препятствия Payon Forest теперь показаны камнями на траве, а не тёмными квадратами. Скалы имеют каменные грани вместо рисунка из прямоугольных отверстий. Сетка столкновений, навигация, параметры монстров и сохранения не изменены.

Проверки: 100 тестов, включая синхронную загрузку из кеша, повторные запросы, медленный ответ, точное сохранение исходных PNG-чанков и оформление непроходимых клеток. Браузерный набор проверяет декодирование всех 65 спрайтов, а также отдельно обрыв сети и невалидный PNG для Willow в Chromium/WebKit. Снимки Willow и карты сохраняются в артефакте Quality gate.
