# 0.14.0 — улучшения по аудиту

Исправлены периодический урон Venom Dust при непрерывном обновлении яда, несколько параллельных RAF после перезапуска, потеря летящих атак и эффектов после восстановления, сброс двух кинжалов и недоступная кнопка старта на узком горизонтальном экране. Яд сохраняет ближайший тик и сильнейшую активную дозу. Сохранения восстанавливают множества уже поражённых целей, чтобы не наносить повторный урон.

Доступны семь сборок: Knight, Hunter с луком или соколом, Wizard с огнём или льдом, Assassin с катаром или двумя кинжалами. До старта сборка задаёт начальные характеристики и оружие; в паузе кнопка распределяет имеющиеся очки по её приоритетам с учётом зависимостей. Ручной выбор навыков остаётся доступен. Меню показывает рекомендуемый навык и параметры следующего уровня.

В настройках боя добавлены обычный режим, приоритет контроля, экономия SP, резерв маны 0/25/50% и приоритет боссов. Резерв ограничивает атакующие навыки, сохраняя возможность защиты. Панель навыков объясняет ожидание каста, откат, недостаток SP, резерв, ограничения оружия и отсутствие подходящей цели. HUD показывает длительности классовых эффектов и заряды Safety Wall; над противниками видны состояния контроля и яда.

Часть обычных монстров получила дальние снаряды, рывок с предупреждающей линией или опасную область с задержкой. Боссы также создают отмеченные области. От предупреждения можно уйти; снаряды и зоны сохраняются между сессиями. Это новые механики Survivor, не реконструкция оригинального AI Ragnarok. Параметры исходной базы HP/EXP и множители опыта не изменены. Safety Wall защищает от контакта, но не от дальнего снаряда или зоны.

Итог забега показывает длительность, уровень, убийства и боссов, этапы эволюции, вклад источников урона и последний полученный удар. Использование бесконечного HP/SP отмечается как тренировочный режим.

Симуляция выполняется с фиксированным шагом 1/60 секунды через единственный отменяемый RAF. Из интеграционного файла вынесены часы (`clock.js`), интерфейс (`interface.js`), политика навыков (`combat-policy.js`), отчёты и индикаторы (`insights.js`), поведение монстров (`monster-ai.js`). Версия runtime хранится в `data/version.js`; тест проверяет совпадение с package.json и URL ресурсов.

Проверки: `npm ci`, `npm test` (81 проверка), `npm run test:browser` (Chromium), `BROWSER_ALL=1 npm run test:browser` (Chromium и WebKit). Браузерный набор проверяет четыре ветки, настройки и доступность старта на 320×480, 390×660, 844×390 и 1366×768 с настоящим Canvas и RAF. Workflow Quality gate запускает оба браузера и публикует GitHub Pages только после успешных проверок; снимки экранов сохраняются в артефакте CI. WebKit на Linux не заменяет проверку на физическом iPhone, а симуляции не подтверждают баланс полного прохождения.
