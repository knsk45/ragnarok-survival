# 0.8.1 — Experience rates

- Base EXP ×5 and Job EXP ×2, configured in `RS_DATABASE.settings.experienceRates`.
- Rates are applied once when collecting experience crystals. Canonical monster rewards and level requirement tables are unchanged.
- The pause menu displays both rates on every tab, separately from game speed.
- Existing 0.8.0 saves remain compatible; the new rates affect subsequent pickups.
