# Ragnarok Survival — data layer

Папка содержит контент игры отдельно от игрового цикла. Движок читает `database.js`, который собирает версии схемы и отдельные таблицы.

## Таблицы

- `monsters.js` — монстры, идентификатор iRO, классификация, параметры боя, опыт, визуальный ключ и источник.
- `jobs.js` — профессии, бонусы характеристик и переходы эволюции.
- `characters.js` — игровые персонажи и последовательности профессий/спрайтов с `sourceRefs`.
- `skills.js` — классическое дерево навыков, уровни, SP, cooldown, профессия и зависимости `requires`; quest/soul-link навыки помечаются как `spendable: false`.
- Skill Points начисляются по Job Level: 9 у Novice, 49 у Swordman и 49 у Knight.
- `builds.js` — автоматические билды, включая Hybrid Knight и их `sourceRefs`.
- `progression.js` — контрольные точки Base/Job Level и переходы профессий.
- `stats.js` — список характеристик и формула стоимости очков.
- `sources.js` — каталог первоисточников и стабильные `sourceRefs` для профессий, навыков и монстров.
- `database.js.settings.maxEnemies` — ограничение одновременно живых монстров для контроля нагрузки на мобильных браузерах.
- `database.js.settings.enemyPowerCap` — верхний предел масштабирования силы монстров; используется вместе с `maxEnemies`.
- `database.js.settings.bossHpMultiplier` — множитель HP элитных боссов.

## Правила расширения

1. Не переименовывать существующие `id` — они используются сохранениями и зависимостями.
2. Новые записи добавлять с новым `id`, не заменяя старые.
3. При изменении формата увеличивать `schemaVersion`.
4. При изменении баланса увеличивать `contentVersion` и оставлять источник/комментарий.
5. Для навыка указывать `stateKey`, `maxLevel`, `requires`, `spCost` и `cooldown`.
6. Для монстра указывать `id`, `source`, `stats`, `combat` и `visual`; прототипные параметры помечать `source: 'prototype'`.
7. Для новой профессии сначала добавить первоисточник в `data/sources.js`, затем указать его id в `sourceRefs` профессии, навыков и связанных монстров.

## Первоисточники

`data/sources.js` — единый реестр ссылок. В игровых таблицах сохраняются стабильные идентификаторы, а не копии URL:

- профессии: iRO Wiki Classes / Novice / Swordman / Knight;
- навыки: страницы профессий и Old iRO Wiki Skill Simulator, включая дерево Knight;
- монстры: iRO Wiki Monster Database и отдельные карточки монстров.

URL можно обновлять централизованно в реестре, не меняя записи и зависимости игрового контента.

## Версионирование

GitHub хранит историю изменений всей базы. Старые данные не удаляются без отдельной миграции: новые балансные значения должны оформляться отдельным коммитом, а удаление записи — только после появления совместимого `deprecated: true`.
